Для того, чтобы обучиться базовому владению инструментами\языку, игрок должен суммарно набросать 100% с помощью куба д20 + модификатор Инт.

## Языки.

Выучить язык самостоятельно невозможно. Для изучения необходим наставник. При броске ученик и наставник бросают д20 +интеллект (один учит - другой учится). В случае, если один из участников суммарно получил меньше 8 - его результат берется с отрицательным значением. Финальный результат считается по формуле (ученик + наставник) / 2.

## Инструменты.

  
Изучение владения инструментами - это самостоятельные изыскания. Для изучения необходим соответствующий набор инструментов + необходимые компоненты. В случае трёх критических неудач за время изучения - набор инструментов ломается.
